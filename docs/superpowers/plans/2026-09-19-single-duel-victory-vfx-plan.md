# 单场战斗胜利特效实施计划

## 目标

按照 `docs/superpowers/specs/2026-09-19-single-duel-victory-vfx-design.md`，为玩家单场胜利增加一次约 1.3 秒的全屏水墨演出，并在普通终局与完整回放终局中保持一致。

## 1. 建立基线

- 检查并保留当前工作区改动。
- 运行 `powershell -ExecutionPolicy Bypass -File tools/run_tests.ps1`，确认行为修改前基线通过。

## 2. 制作素材

- 生成透明背景、无文字、无边框的水墨爆散 PNG，保存到 `art/vfx/victory_ink_burst.png`。
- 生成约 0.8 秒、无音乐和其它打击声的低沉单次锣声音效，保存到 `audio/sfx/victory_gong.wav` 或 `audio/sfx/victory_gong.ogg`。
- 检查透明通道、留白、移动端尺寸和音频首尾静音，避免纹理脏边或音频爆音。

## 3. 创建独立表现组件

- 新增 `scripts/victory_vfx.gd`，负责唯一一次播放、复位、输入拦截、tween、音频和 `finished` 信号。
- 新增 `scenes/victory_vfx.tscn`，包含暗幕、墨浪、实时“胜”字和专用 `AudioStreamPlayer`。
- 集中声明时长、暗幕透明度、文字缩放和墨浪尺寸等可调参数。
- 提供不依赖真实等待时间的调试完成入口，便于集成测试稳定推进。

## 4. 接入战斗终局

- 在 `scenes/duel.tscn` 中把 `VictoryVfx` 放到战斗画布最高表现层。
- 在 `scripts/duel_controller.gd` 中将终局状态保存与终局控件显示拆开：胜负仍立即记录，胜利时先隐藏比分和归程按钮并启动特效。
- 特效完成后恢复现有状态文字和 `打道回府`。
- 播放期间阻止回放、卡牌检查、离开和其它输入。
- 完整回放再次抵达胜利终局时复用相同入口；失败终局保持现状。
- 节点或可选素材不可用时立即回退到现有终局显示。

## 5. 添加自动化覆盖

- 扩展 `tests/test_duel_integration.gd` 或新增聚焦测试，验证胜利播放、失败不播放、播放期间控件隐藏、完成后恢复及重复调用不叠加。
- 扩展 `tests/test_duel_undo.gd`，验证完整回放抵达胜利终局时再次播放且回放流程不被卡住。
- 测试使用静音总线或虚拟音频驱动，不实际播放声音。

## 6. 验证

- 先运行新增的聚焦测试。
- 运行完整测试套件。
- 静音启动游戏，在 `540×960` 和短屏窗口手动检查胜利、失败、回放三条路径。
- 检查 Android 友好的透明渲染、帧率和触摸拦截；本轮除非用户另行要求，不导出 APK。
