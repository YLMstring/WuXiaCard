# 寒冰真气与天外玉龙实施计划

## 目标

按 `docs/superpowers/specs/2026-08-11-hanbin-tianwai-design.md` 实装
`HanBinZhenQi3/4` 与 `TianWaiYuLong2/3`，保持模拟器权威、规则卡牌无关，并覆盖
敌方手牌主动目标、分阶段翻面清理、内力变化触发、单卡揭示、跨动作点数批次与触发牌
交换攻击。

## 任务 1：建立失败用例

文件：

- 新建 `tests/test_hanbin_tianwai_abilities.gd`
- 修改 `tools/run_tests.ps1`

步骤：

1. 固定目录词汇和四张卡牌非空能力声明。
2. 为分阶段翻面写最小模拟器用例：普通非保留能力先失去；独立自身翻面后能力可触发；
   事件期间新授予能力保留；旧翻面后能力最后失去。
3. 为寒冰主动目标、最后内力顺序、阴阳掌力主动/自动差异和同步衰减写用例。
4. 为天外玉龙四方向交换、三阶加点、交换后攻击及失败停止写用例。
5. 运行新套件，确认失败来自尚未注册的通用词汇和空能力声明。

## 任务 2：目录词汇与校验

文件：

- 修改 `scripts/card_catalog.gd`
- 修改 `tests/test_card_catalog.gd`

步骤：

1. 注册敌方手牌目标、内力变化事件与条件、精确单卡揭示、触发牌交换和对方所有者引用。
2. 允许相关动作声明精确卡牌引用、观察者和跨动作点数批次组。
3. 校验“自身翻面后”能力条目只能包含唯一的对应触发，不能同时声明其他触发、
   `activation` 或 `modifiers`。
4. 补齐合法/非法目录夹具，保持错误信息卡牌无关。

## 任务 3：敌方手牌主动目标与精确快照

文件：

- 修改 `scripts/duel_targeting.gd`
- 修改 `scripts/duel_ability_executor.gd`
- 修改 `scripts/duel_simulator.gd`
- 修改相关纯规则测试

步骤：

1. 枚举发动时对手当前手牌的逻辑索引，产生 `TARGET_HAND_SLOT` 动作。
2. 在支付费用前把目标精确实例、所有者和逻辑位置写入激活上下文快照。
3. 费用后的动作复用同一上下文，不能因来源翻面重新捕获目标。
4. 新增精确单卡揭示动作；已揭示、缺失或离区目标返回 `NO_EFFECT`。
5. 保证主动选择阴阳掌力合法，减点守卫无效果后仍继续揭示。

## 任务 4：内力变化触发与分阶段翻面

文件：

- 修改 `scripts/duel_ability_executor.gd`
- 修改 `scripts/duel_triggers.gd`
- 修改 `scripts/duel_simulator.gd`
- 修改 `scripts/duel_abilities.gd`
- 修改翻面相关测试

步骤：

1. 每个成功内力变化动作发出事件后立即提交通用内力变化触发上下文。
2. 条件支持“变化牌是自身”与“旧值为正、新值为零”。
3. 泛化非攻击翻面所有者引用，使能力来源可翻到其对方所有者。
4. 翻面开始时快照能力条目；先清除普通非保留能力并发事件。
5. 保留独立的非保留自身翻面后条目，结算 `CARD_AFTER_FLIPPED`，再按旧快照精确删除
   这些条目；期间新授予能力不被删除。
6. 对攻击、非攻击、阻止翻面、临时压制批次和现有翻面后反应跑回归。

## 任务 5：寒冰真气声明与同步衰减

文件：

- 修改 `scripts/card_catalog.gd`
- 修改 `scripts/duel_ability_executor.gd`
- 扩展 `tests/test_hanbin_tianwai_abilities.gd`
- 必要时修改 `tests/test_power_change_integration.gd`

步骤：

1. 声明共用敌方手牌主动能力。
2. 声明四阶最后内力翻面规则。
3. 声明独立非保留自身翻面后授予条目，不使用 `retained_on_flip`。
4. 声明非保留回合开始衰减能力：自身减一，自动选择最左两个可变点数手牌减一。
5. 支持多个顶层动作声明同一过渡期点数批次组，验证三目标共享前置停顿和动画起点。
6. 覆盖少于两个合法目标、阴阳掌力顺延、自身/手牌归零移除和再次翻面永久失去。

## 任务 6：天外玉龙交换攻击

文件：

- 修改 `scripts/duel_ability_executor.gd`
- 修改 `scripts/card_catalog.gd`
- 扩展 `tests/test_hanbin_tianwai_abilities.gd`

步骤：

1. 新增与精确触发牌交换动作，复用既有双腿移动与移动前后事件。
2. 交换成功后更新能力来源格；失败返回 `NO_EFFECT`，由 `STOP_RULE` 阻止攻击。
3. 二阶声明交换后标准攻击。
4. 三阶声明触发牌先加一，再交换并攻击；阴阳掌力加点无效果但不停止。
5. 覆盖多来源顺序重验、触发牌后续进场阶段及新位置普通攻击。

## 任务 7：生产控制器手牌目标表现

文件：

- 修改 `scripts/duel_controller.gd`
- 修改或新建寒冰真气集成测试

步骤：

1. 棋盘主动卡拖动时收集棋盘和手牌两类合法动作，不把手牌目标压缩为棋盘索引。
2. 根据指针命中的固定手牌槽和槽内精确实例生成手牌目标动作。
3. 高亮合法敌方手牌槽；普通模式保持背面且不读取展示元数据。
4. 扩展调试激活入口支持目标种类，验证鼠标/触摸等价、无效槽反馈和揭示后的原视图同步。
