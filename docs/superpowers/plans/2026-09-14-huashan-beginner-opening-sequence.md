# 华山进阶零新手序章对战实施计划

日期：2026-09-14

对应设计：`docs/superpowers/specs/2026-09-14-huashan-beginner-opening-sequence-design.md`

## 目标

为新建的华山派进阶零轮次增加两场固定序章战。序章胜负均提供一阶奖励，
但不计入有效对局、正式胜场、最终得分或结局名单；第三位固定敌人少镖头·
林平之开始完全恢复正常流程。

## 任务一：记录基线并锁定敌人目录契约

修改：

- `scripts/enemy_catalog.gd`
- `tests/test_enemy_catalog.gd`

步骤：

1. 在行为修改前运行完整测试套件并保存结果。当前用户刚加入等级 0 敌人，
   若目录测试只因现有等级校验不接受该条目而失败，将其记录为本功能的预期
   红灯；其它失败必须先查明。
2. 先写测试，要求 `dukou_daoshi` 是等级 0、`special_only = true`，可通过
   目录校验，但不属于任何普通等级候选，普通随机选择也不能返回它。
3. 给目录校验加入可省略的布尔 `special_only`：只有显式专用敌人才允许等级
   0，普通敌人仍必须为 1–15 级。
4. `get_enemy_ids_for_level()` 统一排除专用敌人；精确 ID 查询和 AI 基准目录
   仍可读取该定义。
5. 调整目录覆盖测试，分别验证普通候选覆盖所有非专用敌人、专用敌人只通过
   精确查询存在。

## 任务二：建立可迁移的序章存档状态

修改：

- `scripts/deck_profile_store.gd`
- `tests/test_deck_profile_store.gd`
- `tests/test_ending_profile.gd`

步骤：

1. 存档版本升至 15，默认档加入整数 `beginner_opening_stage = 0`。
2. 老版本修复／迁移一律补为 0，不根据门派、难度、等级或敌人 ID 推断。
3. 新建华山进阶零轮次时设置阶段 1、等级 1、当前敌人
   `dukou_daoshi`；忽略普通等级 1 随机选敌。其它组合保持当前选敌方式。
4. 添加窄查询和内部判断，统一识别当前是否处于序章；避免主流程控制器直接
   读取字段或判断敌人 ID。
5. 扩展 `is_profile_valid()`：
   - 阶段 1／2 仅允许华山、进阶零、等级 1、零有效对局、空正式击败历史，
     并要求对应固定敌人；
   - 阶段 0 保留敌人等级等于玩家等级的普通校验；
   - 非活跃轮次只能为阶段 0。
6. 轮次重置、通关和归隐通过默认档路径清零阶段；待领取奖励和卡组修改保留
   当前阶段。
7. 覆盖默认档、旧档迁移、合法阶段、非法组合、保存恢复和重置。

## 任务三：实现序章胜负事务

修改：

- `scripts/deck_profile_store.gd`
- `tests/test_deck_profile_store.gd`
- `tests/test_ending_profile.gd`

在 `record_completed_duel_and_save()` 的有效性检查之后、普通有效对局计数之前
处理序章结果：

1. 序章失败：保持阶段、敌人、等级、有效对局和正式击败历史不变并保存；
   返回未完成、未推进。
2. 序章胜利继续提交本局熟练度候选，但不增加有效对局、不追加正式击败
   历史、不检查通关阈值、不解锁敌人门派、不调用普通升级函数。
3. 阶段 1 胜利：切换为阶段 2、当前敌人 `dukou_xiaoke`、等级仍为 1，清空
   敌方手牌记忆。
4. 阶段 2 胜利：切换为阶段 0、当前敌人 `qingfeng_xuedi`、等级仍为 1，
   清空敌方手牌记忆。
5. 阶段切换返回 `advanced = true`，使其语义继续表示“对手／进度已推进”，
   但 `added_ids` 为空。
6. 第三战已经是阶段 0，自动走原有普通胜利路径：正式计数为 1、击败名单
   记录少镖头、等级升至 2、执行跨等级解锁并选择等级 2 敌人。
7. 测试序章失败重试、两次胜利推进、熟练度提交、第三战恢复以及 12 场正式
   胜利才触发结局。

## 任务四：锁定一阶奖励和场景衔接

修改：

- `scripts/deck_profile_store.gd`
- `tests/test_reward_profile.gd`
- `tests/test_main_flow.gd`

步骤：

1. 奖励候选仍通过唯一的现有筛选／洗牌实现生成；增加具名的奖励档位计算，
   序章强制返回一阶，普通流程返回当前人物品阶。
2. 验证序章一、序章二在胜利和失败后都生成最多三张一阶牌，继续排除已解锁
   卡牌并遵守本轮门派池。
3. 验证序章二胜利已经把当前敌人切到少镖头时，本次待领奖励仍是一阶；奖励
   领取后组牌界面显示少镖头。
4. 验证奖励为空时直接回到组牌界面且阶段／敌人保持正确。
5. 主流程不新增序章判断；继续调用存档层的完成对局、生成奖励和领取奖励
   接口。
6. 更新现有华山进阶零集成夹具：教程完成后显示爱护师弟；两场序章胜利后
   才进入少镖头；少镖头胜利后才断言等级 2。
7. 增加其它门派进阶零与华山进阶一的回归断言，确认它们仍从普通等级 1
   敌人开始并在首胜后升级。
