# 底部提示文字颜色与静音实机测试设计

## 目标

门派选择、组牌和战斗场景的底部提示文字统一使用卡牌详情中“背景”正文的深灰褐色
`Color(0.42, 0.34, 0.27, 1)`。文字内容、字号、位置、状态切换和其它界面颜色均不改变。

以后由开发代理启动的实机或桌面运行测试必须静音音乐与音效；玩家正常启动游戏时的声音行为不改变。

## 实现

- 在共享的选择界面样式入口声明底部提示色，并让门派选择与组牌场景显式应用，避免依赖继承主题。
- 战斗场景的 `TurnStatus` 使用同一颜色常量或同值显式覆盖。
- 所有提示状态——默认提示、难度说明、锁定提示、查看详情、保存失败、先攻限制和战斗回合提示——只替换文字，不再改变颜色。
- 自动化 headless 测试继续使用无声运行。需要启动可见游戏做运行验证时，使用静音音频驱动或先静音主音频总线；不通过修改正式音乐/音效设置实现。

## 验证

- 门派选择集成测试检查难度切换、锁定状态和详情状态下的有效字体颜色均与卡牌背景正文一致。
- 组牌集成测试检查默认提示与先攻限制提示均与卡牌背景正文一致。
- 对局集成测试检查 `TurnStatus` 在初始状态和回合状态更新后均与卡牌背景正文一致。
- 运行相关聚焦套件；本次只涉及表现，不改变玩法规则。
