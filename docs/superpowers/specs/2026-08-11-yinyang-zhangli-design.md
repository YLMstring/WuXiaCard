# 阴阳掌力与 −1 点数规则设计

日期：2026-08-11

## 目标

实装 `YinYangZhang3` 与 `YinYangZhang4` 的完整卡牌能力，并把四边全为
`-1` 的牌定义为一种通用、卡牌无关的特殊点数形态：不显示点数、能够被任意
非负攻击点数击败、不能成为加减点数动作的目标。

实现继续遵守单一规则路径：人类、测试模式、贪心回退和深度搜索都通过
`DuelSimulator`、`DuelRules`、通用执行器与纯数据事件结算。规则和搜索不得检查
阴阳掌力的卡牌 ID。

## 玩家可见行为

### −1 点数

只有当前四边点数严格等于 `[-1, -1, -1, -1]` 的牌使用特殊规则。单独一边为
`-1` 不会令整张牌进入该状态。

- 手牌、棋盘、牌组预览和其他 `CardView` 场景都隐藏四个点数标签。
- 正常非负攻击点数都大于 `-1`，所以只要位置和所有权满足攻击规则，该牌即可被攻击。
- 该牌不能成为 `ACTION_CHANGE_POWERS` 的目标；正向和负向变化都无效，不发出
  `powers_changed`，也不会因减点进入全零移除流程。
- 有选择数量上限的批量点数效果在计算上限前排除该牌。例如紫霞功四级选择场上
  前两个其他友方时，若行优先候选中包含阴阳掌力，则跳过它并继续选择下一个合法目标。

### 阴阳掌力进场

阴阳掌力仍遵循普通出牌阶段：先放入目标格，结算既有全局
`TRIGGER_CARD_SUMMONED` 响应，再进入自身 `TRIGGER_CARD_AFTER_SUMMONED` 阶段。
若其精确实例在自身阶段前已经离场，自身能力不结算。

自身能力按以下顺序执行：

1. 将阴阳掌力自身移入原始拥有者的 removed zone，发出既有自我移除事件。
2. 为其结算时拥有者抽一张牌；牌库为空时该步骤无效果，但后续步骤继续。
3. 对抽牌完成后手牌中所有友方掌法精确实例授予阴阳掌力效果。

因此本次新抽到的牌如果是掌法，也会获得效果。阴阳掌力已经离场，不进行通常的
进场后标准攻击。若手牌中没有掌法，则只发生自我移除与可能的抽牌。

## 授予能力

授予仅影响步骤 3 执行时位于该拥有者手牌中的掌法精确实例。之后新抽到的牌不会
追溯获得能力。授予能力不是 `retained_on_flip`，因此目标牌翻面时按现有规则失去。

能力拆成可复用的通用组成，以安全处理多次授予：

- 一个共同的“首次攻击后再发起一次标准攻击”触发能力。三级和四级使用完全相同的
  声明，因此重复授予会由现有结构去重，不会叠加成三次或更多攻击。
- 一个直线距离两格攻击修饰。三级只允许中间格为空；四级允许中间格为空或属于
  攻击者当前拥有者的友方。四级规则是三级的超集；两个修饰同时存在时取更宽范围。

目标牌原本的相邻攻击能力不受影响。远程攻击仍使用朝向目标的对应攻击边和目标的
相向防守边进行严格大于比较。

## 再攻语义

一次“攻击”继续表示现有完整标准攻击：读取当前精确实例的位置与拥有者，按
上、右、下、左方向寻找合法目标，每个目标的攻击、翻面和触发完整结算。

第一次攻击及其全部响应完成后，阴阳掌力授予的触发请求一次新的标准攻击：

- 第二次攻击重新读取棋盘，不复用第一次的目标快照。
- 若攻击者移动，则从新位置攻击；若已被移除、失去所有权资格或翻面并失去该能力，
  不再发起第二次攻击。
- 第二次攻击仍发出普通攻击事件并允许其他“攻击后”能力响应。
- 攻击请求携带纯数据的“重复攻击”标记；阴阳掌力的再攻条件拒绝该标记，从而只
  阻止自身递归，不屏蔽其他攻击后规则。

## 通用规则原语

### 特殊点数判定

在纯规则层提供一个通用判定，输入卡牌或四边点数，输出其是否为四边全 `-1`。
`CardView`、点数执行器和选择器条件共享这一语义，不分别复制卡牌 ID 判断。

### 点数目标合法性

新增通用选择条件“所选卡牌的点数可以改变”。所有以 selected card 为目标的
`ACTION_CHANGE_POWERS` 批量声明显式包含该条件，使 `limit` 只统计合法目标。
执行器同时保留最终防线：无论动作通过选择器、触发卡引用或能力来源引用直接到达，
四边全 `-1` 都返回 `NO_EFFECT`。

目录验证需要识别新条件，并确保使用 selected card 进行点数变化的选择器带有该
条件，避免未来卡牌忘记声明后再次出现“占用上限但不生效”的行为。

### 远程攻击修饰

新增通用直线距离两格攻击修饰，数据声明中包含是否允许中间友方。`DuelRules`
统一枚举相邻和合法的两格目标，供通常攻击、能力发起攻击、反应攻击、AI 和测试
共同使用。中间格为敌方时不能越过；不得横向跨行或越出棋盘。

### 离场后的来源上下文

能力开始时已有的纯数据来源快照保存精确实例、结算时拥有者和原位置。自我移除后，
后续抽牌与手牌选择只使用该不可变快照中的拥有者；不得保留场景节点或可变卡牌引用。
这使通用有序动作可以安全表达“先离场，再为原拥有者继续结算”。

## 事件与表现

预期事件顺序为：

1. `ability_triggered`
2. `card_exiled`（`self_removal = true`）
3. 可选的 `card_drawn` 及相关揭示事件
4. 每个获得能力的精确手牌实例对应 `ability_gained`

控制器沿用现有自我渐隐、抽牌和手牌能力同步路径，不新增 VFX、音效或场景节点。
四边全 `-1` 的已揭示卡只隐藏数字，卡图、名称、内力、所属方和可检查性保持不变；
暗牌继续不得泄漏任何元数据。

## 结构草图

本功能不新增节点，只修改现有数据和规则链：

```text
CardCatalog
├── 阴阳掌力 3/4 数据声明
├── 点数可变选择条件
├── 距离两格攻击修饰
└── 非递归再攻条件/动作字段

DuelSimulator / DuelRules
├── 卡牌无关攻击范围枚举
├── 重复攻击上下文
└── 完整第二次标准攻击

DuelAbilityExecutor / DuelCardSelector
├── 离场后的来源拥有者快照
├── 当前手牌掌法授予
├── 点数动作最终免疫检查
└── limit 前的合法目标过滤

CardView
└── 四边全 −1 时隐藏四个既有 Label
```

## 固定参数

本功能没有需要在 Inspector 调节的动画或数值参数。以下均为卡牌规则常量：

- 特殊点数：四边全部为 `-1`
- 额外攻击距离：正交两格
- 再攻次数：一次
- 抽牌数：一张
- 三级中间格：仅空格
- 四级中间格：空格或友方

## 边界与失败行为

- 牌库为空：自我移除成功，抽牌无效果，仍向现有手牌掌法授予能力。
- 没有掌法：自我移除和抽牌照常，授予阶段无事件。
- 手牌原本四张、打出阴阳掌力后抽一张：抽牌后最多仍为五张，随后检查全部手牌。
- 同一掌法先后获得三级和四级：再攻只保留一份，攻击范围使用四级超集。
- 同一掌法重复获得相同等级：结构去重，不重复发出实质能力或增加再攻次数。
- 远程方向中间为敌方：只能按普通相邻规则处理该敌方，不能攻击其后的牌。
- 第一次攻击后没有合法目标：仍视为一次已完成攻击；再攻重新检查，若仍无目标则
  不产生翻面，但不会继续递归。
- 目标四边全 `-1`：任何非负攻击边都满足严格大于；所有权、直线和阻挡规则仍必须合法。
- 以四边全 `-1` 卡为直接点数目标：动作 `NO_EFFECT`，不改变状态版本之外的规则结果，
  不发出点数动画事件。

## 验证范围

### 目录与通用原语

- 阴阳掌力 3/4 的声明通过目录验证且不再是空能力数组。
- 新选择条件、攻击修饰和重复攻击字段接受合法数据并拒绝未知键或非法类型。
- 四边全 `-1` 判定只匹配完整哨兵，不误判单边 `-1` 或普通零点牌。

### 点数与选择器

- 直接正向、负向和动态点数变化都不能修改四边全 `-1` 卡，也不发出事件。
- 无上限批量效果跳过哨兵卡。
- 紫霞功四级的 `limit = 2` 在行优先候选中跳过哨兵并选择后续两个合法友方。
- 隐藏点数不影响固定五手牌槽、检查器或暗牌保密。

### 攻击

- 普通非负攻击边可以攻击相邻的四边全 `-1` 敌方。
- 三级掌法可攻击隔一个空位的直线敌方，不能越过友方或敌方。
- 四级掌法可越过一个友方或空位，不能越过敌方。
- 上、右、下、左方向、边界和横向不跨行全部覆盖。
- 远程攻击进入现有攻击、翻面、反应和重验证路径。
- 第一次完成后第二次重新取目标；重复攻击不触发自身第三次攻击，但其他攻击后能力可触发。

### 完整卡牌流程

- 自我移除严格先于抽牌，抽牌先于手牌掌法授予。
- 新抽到的掌法获得能力；非掌法不获得。
- 牌库为空与没有掌法时仍完成剩余合法步骤。
- 自身阶段前离场时不抽牌、不授予。
- 多次三级/四级授予不会叠加再攻，四级范围覆盖三级。
- 获得能力的掌法翻面后失去非保留效果。
- AI 克隆、状态键、回放与实时对局产生相同结果。

完整实现后运行：

```powershell
powershell -ExecutionPolicy Bypass -File tools/run_tests.ps1
```

并在 540×960 纵向视口走查阴阳掌力自我移除、抽到掌法、能力同步、三级/四级远程
攻击、第二次攻击，以及紫霞功跳过阴阳掌力选择后续目标。
