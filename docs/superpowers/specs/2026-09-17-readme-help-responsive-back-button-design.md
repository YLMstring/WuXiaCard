# 离线说明页返回按钮与短屏适配设计

## 目标

- 将离线 README 说明页的返回箭头移入卷轴布面右上角。
- 在短屏幕上完整显示卷轴顶部与底部木轴，不发生上下裁切。
- 保持正文可读面积，避免为返回按钮单独占用一整行。

## 布局

- 9:16 及更长的屏幕沿用 `MainMenuBackdrop.fit_safe_rect()` 返回的安全区域。
- 短于 9:16 的屏幕使用完整视口宽度，不得通过缩窄到居中的 9:16 区域来伪装短屏适配；背景保持满宽覆盖并上下裁切。
- 卷轴高度由安全区域高度和上下安全边距共同限制；正文区域再由卷轴图片中布面的 UV 比例反算。
- 卷轴在安全区域内垂直居中。无论屏幕高宽比如何，卷轴外框不得超出安全区域。
- 返回按钮仍由帮助页根节点持有，但其位置改为卷轴正文布面的右上角内侧。这样不改变返回信号和主流程结构。
- 返回按钮维持至少 `42×42` 的触控区域。正文首行从左侧开始，按钮位于右侧空白处，不额外压缩正文高度。

## 验证

- 在 `540×960` 参考短屏上检查卷轴上下木轴完整可见，箭头位于卷轴内部。
- 额外在 `540×800` 更短视口上检查卷轴宽度与 `540×960` 基本一致、卷轴高度明显降低、背景满宽并上下裁切。
- 保留现有 README 加载、目录跳转、隐藏滚动条和返回主菜单测试。
- 本次仅运行相关 UI 测试和无声实机走查，不运行完整测试套件。
