# 太极剑与阴阳掌力平衡调整设计

## 范围

本次只调整三张太极剑的共通效果和阴阳掌力的抽牌方式。卡牌描述已更新，模拟器声明、通用规则与测试需要与描述保持一致。

## 太极剑共通效果

`TaiJiSanHuan4`、`TaiJiSanHuan5` 与 `TaiJiDaKui5` 保留现有进场攻击改向规则：敌方牌进场时若与效果来源相邻，并在普通进场攻击前仍保持相邻，本次普通进场攻击只选择攻击者自己的友方，不选择太极剑所属方的友方。

三张牌的同一能力条目还声明一次性消耗规则：

1. 监听 `TRIGGER_CARD_AFTER_ATTACK`。
2. 要求攻击者相对于太极剑当前所属方为敌方。
3. 要求本次攻击至少实际开始攻击一张“攻击开始时与攻击者同属一方”的牌。
4. 使用现有 `ACTION_REMOVE_THIS_ABILITY` 移除包含改向 modifier 的整个能力条目。

消耗不要求太极剑参与改向。由一字电剑或其它效果造成的敌方互攻同样触发。多个太极剑来源同时满足条件时，它们各自发现并结算触发，全部失去效果。

只有产生了 `attack_started` 的真实攻击才会发出攻击后事件。因此点数不足、没有合法目标或攻击开始前取消时不消耗；一旦确实攻击了同阵营目标，即使目标没有翻面也会消耗。

为保持声明驱动，攻击结算在攻击后上下文中记录本次实际开始攻击的目标及其攻击开始时所属方。新增通用触发条件检查其中是否存在与攻击者同属一方的目标，不写卡牌 ID 分支。

## 阴阳掌力抽牌

`ACTION_DRAW_CARDS` 增加可选的 `weapon` 过滤字段。普通抽牌仍只声明 `amount`；只有需要过滤时才声明额外字段。

阴阳掌力三级和四级的进场动作改为：

```gdscript
{
	"type": ACTION_DRAW_CARDS,
	"amount": 2,
	"weapon": "掌法",
}
```

每次从当前牌库顺序中取出第一张武器类型为“掌法”的牌，重复至两张、手牌已满或牌库中没有合法牌。被跳过的非掌法牌留在牌库原位，相对顺序不变。

过滤抽牌在找不到掌法时不生成空牌库保底的太祖长拳。若手牌只有一个空位，则只抽一张。每张成功抽取仍逐张发出既有 `card_drawn`、揭示与 `CARD_AFTER_DRAWN` 事件。

抽牌完成后，阴阳掌力继续按现有顺序向手牌中全部掌法授予能力，因此两张新抽到的掌法也会获得效果。

## 测试

- 三张太极剑目录声明均包含改向 modifier 和一次性攻击后触发。
- 相邻敌方进场攻击被改向并实际互攻后，所有满足条件的太极剑失去该能力。
- 一字电剑等其它来源造成的敌方互攻也消耗效果。
- 点数不足、零目标或只攻击太极剑所属方的牌时不消耗。
- 阴阳掌力按牌库顺序抽取前两张掌法，保留被跳过牌的顺序。
- 覆盖只有一张掌法、手牌仅一个空位、没有掌法和空牌库。
- 每张过滤抽牌继续逐张触发抽牌事件与既有授予逻辑。
