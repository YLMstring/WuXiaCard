# 每轮门派池设计

## 目标

每轮游戏开始时，在玩家选择的门派之外，从门派目录随机选出五个不同门派，组成该轮固定的“门派池”。门派目录中既不是玩家门派、也不在门派池内的门派称为除外门派。除外门派的卡牌不参与开局三张随机牌或战后随机奖励；不属于门派目录的卡牌不受限制。

门派池是轮次进度数据，不是全局解锁数据，也不进入对局状态或 AI 搜索状态。

## 新轮初始化

`DeckProfileStore.begin_run_and_save()` 按以下顺序建立新轮：

1. 验证玩家选择的门派、难度和当前存档状态；
2. 读取 `Sects.get_all_sect_ids()`，排除玩家选择的门派；
3. 使用本次新轮已有的随机数生成器洗牌，从中取五个不同门派；
4. 将抽取顺序保存为 `run_sect_pool_ids`；
5. 使用同一门派池过滤开局三张随机牌候选；
6. 完成既有的门派一级牌解锁、主卡组建立和新轮保存。

只要可选目录门派不少于五个，门派池必须恰好包含五个不同门派。门派是否已经全局解锁不影响入池资格。池内顺序在本轮固定，也作为奖励界面的显示顺序。

## 卡牌门派判定

过滤时先建立门派目录中所有定义的 `glyph` 集合，并读取卡牌目录定义的 `sect`：

- 若卡牌 `sect` 不在门派目录 `glyph` 集合中，该牌不受门派池限制；
- 若卡牌 `sect` 等于玩家门派 `glyph`，该牌合法；
- 若卡牌 `sect` 等于任一门派池门派的 `glyph`，该牌合法；
- 其余目录门派牌属于除外门派，不合法。

因此 `江湖`、`棋仙派`等目录外门派仍按原规则进入随机候选。判定只依据稳定的门派 ID 与其目录 `glyph` 映射，不使用界面文字反向推断 ID。

## 开局三张随机牌

现有开局牌规则保持不变：太祖长拳、一级吐纳术和玩家门派全部一级牌先按既有规则处理，再从其余合法一级牌中随机选三张。新增门派池过滤发生在三张随机牌候选建立阶段：

- 除外门派的一级牌不进入候选；
- 玩家门派和池内门派的牌可以进入候选；
- 目录外门派的牌继续可以进入候选；
- 已拥有牌优先、后备候选、洗牌和补足逻辑维持现状。

## 战后奖励

`DeckProfileStore.create_reward_offer_and_save()` 在应用既有胜负、品阶、解锁状态和难度规则后，再以同一门派判定过滤普通随机奖励候选。

门派池仅限制“随机奖励”：

- 普通胜利奖励和普通战败奖励都排除除外门派；
- 目录外门派继续按原规则参与；
- 目录声明的必定战败奖励沿用独立保证池，不受门派池限制；
- 奖励数量、洗牌、待领取记录和每轮只展示一次等规则保持不变。

## 存档与生命周期

存档 schema 增加：

```gdscript
"run_sect_pool_ids": PackedStringArray()
```

约束如下：

- 活跃轮次必须含有五个不同、存在于门派目录、且不等于玩家门派的 ID；
- 非活跃存档的该字段必须为空；
- 测试模式只临时解锁卡牌，不改写当前门派池；
- 通关、闭关重修和归隐结束当前轮次时清空门派池；
- 下一轮重新随机，不继承上一轮结果。

### 旧存档迁移

旧 schema 的非活跃存档迁移为空池。旧 schema 的活跃存档不结束当前轮次，而是使用该存档中稳定的轮次内容构造固定随机种子，从玩家门派以外确定性选取五个门派。迁移结果立即写入新 schema，之后反复加载不会重抽。

确定性种子不得依赖当前时间、全局随机状态、对象地址或读取次数。相同旧存档内容必须得到相同门派池。

## 奖励界面

奖励选择界面底部的默认提示改为：

```text
门派池：华山派，少林派，……
```

名称来自已保存门派 ID 对应的目录 `glyph`，按池内固定顺序显示。查看卡牌详情时仍临时显示现有的“查看卡牌详情 · 轻触返回”；关闭详情后恢复门派池提示。若损坏数据导致无法取得合法池，界面使用安全的通用提示，但存档加载路径应先完成修复。

## 架构与性能

- 门派池的建立、验证、迁移和奖励过滤归 `DeckProfileStore` 管理；界面只读取格式化所需的数据。
- `SectCatalog` 继续是门派 ID 与显示名的唯一来源；`CardCatalog` 继续是卡牌门派字段的唯一来源。
- 不修改 `DuelState`、原生 C++ 内核、对局规则、状态键、置换表或 AI 搜索。
- 候选过滤只发生在新轮初始化和战后奖励生成，数据量为卡牌目录规模，不进入搜索热路径，无需性能 A/B。

## 测试

- 新轮门派池恰好五个、互不重复、均来自目录且排除玩家门派；
- 固定 RNG 产生可复现的门派池和开局牌结果；
- 旧活跃存档确定性迁移，重复加载不重抽；
- 旧非活跃存档迁移为空池；
- 活跃存档校验拒绝重复、未知、包含玩家门派或数量错误的池；
- 开局随机三张排除除外门派，保留池内门派和目录外门派；
- 胜利与战败普通奖励排除除外门派；
- 目录外门派和必定奖励不受限制；
- 通关、闭关重修与归隐清空门派池；测试模式保留当前池；
- 奖励界面按保存顺序显示门派名称，并在查看详情关闭后恢复；
- 完成聚焦测试后运行完整自动测试套件。
