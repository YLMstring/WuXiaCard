# 难度箭头尺寸与触碰反馈设计

## 目标

缩小门派选择界面两侧的难度箭头，并为触摸和鼠标按压补充清晰、短促的视觉反馈。

## 尺寸与布局

- 箭头按钮由 `42×68` 缩小为 `21×34`，即宽高各为原来的 50%。
- 两个按钮现有的几何中心保持不变；布局代码根据旧中心和新尺寸重新计算左上角位置。
- 左箭头继续水平翻转，左右箭头继续位于卷轴两侧并垂直居中。

## 触碰反馈

- 按下按钮时，以按钮中心为缩放轴，立即缩至静止尺寸的 92%。
- 按下时同时将整体透明度降至 62%，形成与对局回放按钮一致的触碰反馈。
- 松开时使用短促的回弹补间，在约 0.14 秒内恢复到 `scale = Vector2.ONE` 和完全不透明。
- 新一次按下会终止该按钮尚未完成的旧补间，避免快速连点后残留错误缩放或透明度。
- 隐藏或禁用箭头时确保视觉状态恢复，避免重新显示后仍处于按下状态。

## 验证

- 集成测试检查按钮尺寸缩小且几何中心与修改前的布局公式一致。
- 集成测试触发 `button_down` 与 `button_up`，分别检查缩放、透明度和最终恢复状态。
- 在 540×960 竖屏参考视口运行门派选择场景，确认触碰反馈、按钮位置和图片方向。
