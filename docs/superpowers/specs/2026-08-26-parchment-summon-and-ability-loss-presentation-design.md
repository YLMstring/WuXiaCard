# 卷轴、进场停顿与能力失去表现设计

## 目标

统一移除各场景卷轴本体的阴影，增加场上卡牌进场后的阅读停顿，并区分自行失去能力与外部导致的能力失去表现。

## 卷轴阴影

- 在共享 `ParchmentChrome.apply()` 中统一隐藏传入的卷轴阴影节点。
- 该规则覆盖组牌、门派选择、奖励选择中的牌库卷轴，以及各场景共用的卡牌查看卷轴。
- 保留现有阴影节点和函数参数，避免破坏场景节点路径及调用接口。
- 顶部栏、卡牌、内力珠等非卷轴阴影不受影响。

## 场上卡牌进场停顿

- `DuelController` 增加默认值为 `0.5` 秒的统一进场后停顿参数。
- 正常从手牌打出的卡牌在落位动画完成后停顿，再开始表现该次行动产生的各种规则效果。
- 能力生成、复制、复活及重新进场的卡牌在自身进场动画完成后停顿，再继续表现后续效果。
- 每张实际进入场面的牌各自触发一次停顿；由一张牌的效果连续生成多张牌时，每张牌的完整进场及停顿按事件顺序依次完成。
- 初始场面直接放置的八卦方位不属于视觉进场，不触发停顿。
- 抽入手牌或添加到手牌不属于进场，不触发这项停顿。
- 停顿仅存在于表现层，不改变模拟器状态、事件顺序、AI搜索、回放记录或规则结果。
- 快速测试模式将该停顿设为 `0`，避免拖慢既有集成套件。

## 能力失去表现来源

- `ability_lost` 事件携带导致本次能力失去的来源实例 ID；来源语义属于纯数据，不直接声明动画。
- 当来源实例 ID 等于失去能力的目标实例 ID 时，目标牌属于自行失去能力，播放现有灰白闪动。
- 当来源实例 ID 不同或为空时，能力由其它牌、翻面流程或此前施加的待处理压制造成，目标牌静默更新能力数据，不播放灰白闪动。
- 云雾十三式沿用通用来源判断，不增加卡牌 ID 特判。
- 一张牌因为外部效果连续失去多个能力时，每条事件都保持静默，不产生重复闪动。

## 验证

- 共享卷轴测试检查卷轴阴影节点不可见，同时卷轴本体、边框和木轴仍正常显示。
- 对局集成测试检查默认进场后停顿为 `0.5` 秒，快速模式将其清零。
- 表现顺序测试覆盖正常手牌进场和能力生成进场，确认停顿发生在进场动画之后、首个后续效果之前。
- 事件及表现测试覆盖自行失去能力仍会闪动，以及外部效果、翻面和待处理压制导致的能力失去均静默更新。
- 在 540×960 竖屏参考视口实机检查牌库卷轴、卡牌查看卷轴和一次带进场效果的出牌流程。
