# 默认华山新轮自动开始设计

## 目标

当正常模式的玩家只有华山派和进阶零可选时，点击主菜单“踏入江湖”后跳过门派选择界面，直接以华山派、进阶零建立新轮并进入组牌界面。只要玩家已经解锁进阶一或其它任一门派，仍沿用现有门派选择流程。

本功能只缩短唯一选择下的新轮入口，不改变新轮内容、解锁规则、续档规则或测试模式。

## 路由条件

`MainFlowController._on_journey_requested()` 继续按以下优先级处理：

1. 有待领取奖励时进入奖励选择；
2. 有活跃轮次时进入组牌界面；
3. 没有活跃轮次时，判断是否满足默认新轮自动开始条件；
4. 不满足时进入门派选择界面。

自动开始必须同时满足：

- 当前不是测试模式；
- `max_unlocked_difficulty == 0`，即尚未解锁进阶一；
- `unlocked_sect_ids` 恰好只有一个元素；
- 唯一元素为 `HuaShanPai`。

条件使用存档层现有的校验后读取接口，不依据界面当前显示内容判断。门派数组顺序不能改变语义：实现应判断数量和成员，而不是依赖完整数组的顺序。

测试模式始终进入门派选择界面，保留全卡牌测试和手动选择门派、难度的入口。

## 自动开始流程

`MainFlowController` 增加一个只负责判断上述条件的小型辅助方法。满足条件时，直接调用存档层现有的 `begin_run_and_save()`：

- 门派传入 `HuaShanPai`；
- 难度传入 `0`；
- 不启用测试模式的临时全卡牌解锁；
- 其余参数沿用普通新轮的默认行为。

因此，初始牌、敌人顺序、门派池及其它新轮数据仍由唯一的正式新轮创建路径生成并立即写入存档，不在主界面控制器中复制规则。

保存成功后进入组牌界面，与从门派选择界面确认后进入组牌界面的结果一致。场景音乐也沿用现有主菜单到组牌界面的切换逻辑。

## 失败处理

若 `begin_run_and_save()` 保存失败：

- 留在主菜单；
- 显示“保存失败，请重试”；
- 不进入门派选择界面；
- 不把内存中未成功持久化的新轮当成活跃轮次继续。

## 边界情况

- 待领取奖励和活跃轮次的路由优先级不变。
- 玩家只要解锁了进阶一，即使仍只有华山派，也显示门派选择界面。
- 玩家只要解锁了其它任一门派，即使仍只能选择进阶零，也显示门派选择界面。
- 门派解锁数据异常为空或包含未知值时，不自动开始，回退到现有门派选择界面处理。
- 通关、闭关重修、封剑归隐等重置行为不因本功能改变；每次点击“踏入江湖”时均依据当时存档状态重新判断。

## 测试

在主流程集成测试中覆盖：

1. 正常模式的默认新存档点击“踏入江湖”后直接进入组牌界面，并验证存档中的门派为华山派、难度为零且新轮已激活；
2. 测试模式的默认存档仍进入门派选择界面；
3. 已解锁其它门派时仍进入门派选择界面；
4. 已解锁进阶一时仍进入门派选择界面；
5. 保存失败时留在主菜单并显示错误提示。

实现后运行完整测试套件，并在静音的 540×960 窗口中实际走一遍默认新存档和测试模式入口。

## 技术影响

本功能不新增存档字段、卡牌原语、原生 C++ 规则或 AI 搜索分支，也不进入对局结算和搜索热路径。改动范围限定为主界面路由及其集成测试。
