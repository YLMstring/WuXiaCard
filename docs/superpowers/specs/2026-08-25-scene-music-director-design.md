# 场景音乐导演设计

日期：2026-08-25

## 目标

为主流程各界面加入持续背景音乐。音乐由跨场景常驻的展示层统一管理，支持按界面随机、特殊曲目、曲终续播、同池跨界面续播，以及先淡出旧曲再播放新曲的平滑切换。

## 架构

新增 `MusicDirector` 节点并由不会随界面替换而销毁的 `MainFlowController` 持有。各界面控制器不创建播放器，也不自行决定淡出时序。`MainFlowController` 在进入界面时向导演提交音乐上下文及必要特例；导演负责选曲、加载、播放、曲终处理和竞态取消。

音乐是纯展示状态，不进入 `DuelSimulator`、搜索状态、回放记录或卡牌规则。直接单独运行某个子场景时可以没有主流程音乐；生产入口 `main.tscn` 提供完整音乐行为。

## 音乐池

- 主菜单与门派选择：`menu1.mp3`、`menu2.mp3`、`menu3.mp3`，每首等权。
- 战斗：`battle1.mp3` 至 `battle6.mp3`，每首等权。
- 组牌与普通奖励：使用代码中显式声明的固定曲目清单。七首 `village` 曲目各占两个加权条目，四首 `story` 曲目各占一个；新增文件不会自动进入音乐池。精确清单见 `2026-08-26-fixed-story-music-pool-design.md`。
- 通关滚动：通常只播放 `lonely.mp3`；若正常模式本轮解锁过 `KuiHua0`，只播放 `bixie.mp3`。
- 含 `KuiHua0` 的奖励选择：只播放 `terror.mp3`。
- 选择 `KuiHua0` 后下一次进入组牌：只播放一次 `lose.mp3`，之后恢复正常组牌池。

加权随机以曲目为单位。每次抽取相互独立，允许自然结束后再次抽中同一首。

## 同池续播

有两组跨界面续播：

1. 主菜单与门派选择。两者之间双向切换时，若当前曲目属于 `menu1–3`，保持当前位置继续播放。
2. 组牌与普通奖励。两者之间双向切换时，若当前曲目属于正常 `village/story` 池，保持当前位置继续播放。

特殊上下文不属于续播池：

- 从组牌进入含 `KuiHua0` 的奖励时切到 `terror`。
- 从 `terror` 奖励选择其他牌进入组牌时切回正常池。
- 从 `terror` 奖励选择 `KuiHua0` 时，进入组牌播放一次 `lose`。
- 从其它界面进入主菜单、门派、组牌或普通奖励时，按目标规则重新抽取。

## 一次性与本轮状态

`RewardSelectionController.reward_claimed` 携带成功选择的精确卡牌 ID。主流程收到 `KuiHua0` 后设置“下次组牌播放 lose”临时标记。标记在进入该次组牌时立即消费：

- 若 `lose` 自然结束且仍停留在组牌界面，立即回到正常加权池。
- 若玩家在 `lose` 结束前进入战斗，按战斗规则换曲；以后再次进入组牌不会补播 `lose`。

通关音乐必须在卡牌解锁重置前决定。通关摘要记录活动流程在结束前是否已解锁 `KuiHua0`。正常模式据此选择 `bixie`；测试模式临时提供的全卡解锁不算本轮解锁，因此测试模式默认使用 `lonely`。

## 播放与切换

导演保存当前上下文、当前曲目和最新请求代数：

- 当前曲目符合目标续播组时，不重启、不改变播放位置。
- 需要换曲且旧曲正在播放时，先在约 0.6 秒内淡出旧曲，再停止并启动新曲；新曲使用很短的淡入以避免爆音。
- 快速连续切换界面时，旧的异步请求作废，最后一个上下文请求获胜。
- 曲目自然结束后，根据当前上下文重新选曲。单曲上下文会重新播放其唯一曲目；`lose` 结束后则切换为普通组牌上下文。
- 缺失、损坏或无法加载的文件会跳过并给出警告。某音乐池为空时保持静音，不阻塞界面切换。

淡出、淡入时间作为导演可调参数，测试可设为零。

## 数据流

`MainFlowController` 在以下入口设置上下文：

- `_show_main_menu` → 菜单池
- `_show_sect_selection` → 菜单池，允许同组续播
- `_show_deck_builder` → `lose` 一次性特例或正常 village/story 池
- `_show_reward_selection` → 奖励含 `KuiHua0` 时 `terror`，否则正常 village/story 池
- `_show_duel` → battle 池
- `_show_ending` → 正常 `lonely` 或本轮解锁特例 `bixie`

奖励选择成功后，精确所选 ID 先送达主流程，再替换为组牌界面，确保 `lose` 标记在组牌音乐请求前设置。

## 验证

- 所有固定曲目路径存在且能加载。
- village/story 固定清单包含精确声明的 11 首音乐、18 个加权条目，且每首权重分别为 2 和 1。
- 菜单与门派双向续播，不改变当前曲目或播放位置。
- 组牌与普通奖励双向续播，不改变当前曲目或播放位置。
- 战斗、普通通关和辟邪通关选择正确池。
- 含 `KuiHua0` 的奖励只播放 `terror`，其它奖励使用正常池。
- 选择其它奖励不会触发 `lose`；选择 `KuiHua0` 后仅下一次组牌触发一次。
- `lose` 自然结束后恢复正常池；中途离场也消费标记。
- 自然曲终按当前上下文重选，快速切换只执行最后一次请求。
- 淡出发生在新曲启动之前，不出现突兀替换。
- 测试模式临时全解锁不触发 `bixie`。
- 运行完整自动化套件，并实际走主菜单、门派、组牌、战斗、奖励、一次性 `lose` 与通关音乐流程。
