# 静态评估减法消融设计

日期：2026-09-04

## 目标

从生产局面评估中删除牌库价值、相邻危险边和当前行动方价值，并用
112 局真实敌人目录对战判断这组减法是否提升棋力。

## 评估配置

生产默认不再计入：

- 牌库剩余张数的固定价值及牌库中卡牌的点数、内力和能力资源价值；
- 正交相邻敌我牌之间按面对点数比较得到的危险边价值；
- 当前行动方的 `+2/-2` 价值。

场上牌差、手牌数差、手牌与场上卡牌资源、合法行动数和终局评分保持
不变。原生搜索保留三个默认关闭的独立评估开关，仅用于恢复旧特征做
受控消融；生产入口不启用它们。

## 112 局对战

复用 Extended 的 28 组真实敌人目录配对和每组四局换边赛程，共 112
局。双方均使用：

- `self_turn` 固定深度 2；
- PV、History 和 8 MiB 置换表；
- 无时间上限和节点上限；
- 同一原生规则、完整信息和规范平分裁决。

`enhanced` 席位使用减法评估，`baseline` 席位只打开三个旧特征。每局
完成后继续输出并写入进度文件。该实验不套用历史的 55% 发布门槛；
报告实际得分率、终局分差、先后手与牌组分项、回退和非法局，结果再
由开发者与创作者共同判断是否保留。

## 验证

- 添加原生固定局面测试，分别证明三个开关只恢复对应旧分项；
- 验证生产默认评分等于三项关闭的评分；
- 验证双方固定深度均完整达到 2，且没有回退或非法行动；
- 行为改动后运行完整自动化套件，再运行 112 局实验。

基准报告写入 `.summer/local/ai-benchmarks/`，不提交到仓库。
