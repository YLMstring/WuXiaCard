# 卡牌特效正文换行排版设计

日期：2026-09-14

## 目标

在不减少信息、不改写卡牌文案、不改变能力或结算规则的前提下，通过纯文本换行降低卡牌详情中“特效”正文的阅读压力。

本次只调整完整规则的换行位置，不增加简明版、摘要、图标、展开按钮、字体强调或新的玩家操作。“背景”正文保持现状。

## 玩家体验

卡牌详情仍显示目录中的完整 `description`：

- 只在最外层完整句号 `。` 后换行；
- `【】`、`（）()`及引号内部的句号不换行；
- 不增加空白段落、额外段距、项目符号或缩进；
- 不改变任何文字的字号、字重或颜色；
- “特效”正文恢复使用原来的普通 `Label` 及其原有样式；
- “背景”标题及正文完全保持现状。

详情页的轻触关闭、拖动滚动、初始滚动位置和模态输入行为均不改变。

## 格式化规则

`CardEffectTextFormatter` 是纯展示工具。它接收目录原始字符串并返回仅增加换行符的普通文本，不读取目录能力声明，也不生成 BBCode。

扫描字符串时维护中文方括号 `【】`、中文及英文圆括号 `（）()`、中文引号 `“”`、`‘’` 和英文双引号的嵌套状态：

- 只有在所有嵌套深度均为零时，句号 `。` 才是换行边界；
- 句号保留在原句末尾；
- 若句号已经位于字符串末尾或下一字符本来就是换行，不再追加换行；
- 原文已有换行原样保留；
- 逗号、分号、冒号以及任何嵌套结构内部的句号均不触发换行。

例如：

```text
进场后，抽一张牌。锁定：回合结束时，将我移除。
```

显示为：

```text
进场后，抽一张牌。
锁定：回合结束时，将我移除。
```

而：

```text
进场后，获得以下效果：【回合开始时，抽一张牌。翻面前，将我移除。】然后发起攻击。
```

不在 `【】` 内部增加换行。

## 异常回退

以下情况直接返回完整原文，不增加任何换行：

- 任意受支持括号或引号未闭合；
- 出现先闭合后打开的非法嵌套；
- 格式化结果除新增换行外无法还原原文。

由于输出是普通文本，原文中的 `[`、`]` 等字符无需转义，也不会成为样式指令。异常输入只失去换行增强，不会漏字。

## UI 架构

`card_inspector.tscn` 中的特效正文恢复为普通 `Label`：

- 恢复原来的 `font_color` 和 `font_size` 属性；
- 保持中文智能换行；
- 保持由既有外层 `ScrollContainer` 统一滚动；
- 保持忽略鼠标输入，使轻触和拖动手势继续由 `CardInspector` 处理；
- 字号继续由 `CardInspector.set_board_rect()` 按棋盘短边设置原来的 `font_size`；
- 不设置粗体、强调色、段落间距或缩进。

`CardInspector.present()` 仍保存并返回原始卡牌快照。只有写入特效正文控件时调用纯文本格式化器；`get_card_snapshot()` 中的 `description` 永远保持目录原文。

## 数据与规则边界

本功能不修改：

- `scripts/card_catalog.gd` 中任何描述或能力声明；
- 卡牌目录校验；
- `DuelState`、状态键或存档格式；
- 原生 C++ 规则与 AI 搜索；
- 对局事件、动画或输入合法性；
- 背景故事正文。

格式化器是纯 UI 工具，不进入搜索或结算热路径。

## 测试

格式化器测试覆盖：

- 单句正文不增加尾部换行；
- 多个最外层句号逐句换行；
- `【】`、圆括号及引号内部的句号不换行；
- 原有手工换行不重复；
- 普通方括号按原文显示；
- 未闭合和非法嵌套完整回退。

全目录守恒测试遍历每条非空 `description`，移除格式器新增的换行后必须与目录原文一致。详情页集成测试确认特效正文恢复为普通 `Label`、字号和颜色沿用原值、原始快照不变、背景正文不变、滚动及关闭手势不变。

完成后运行完整测试套件，并在音乐和音效静音的情况下，以 `540×960` 检查短文本、多句文本和带 `【】` 文本的实际显示。

## 验收标准

- 玩家看到的能力文字与当前目录逐字一致，仅在最外层句号后增加换行；
- 括号及引号内部不增加换行；
- 字号、字重、颜色和普通 Label 的渲染观感恢复原状；
- 不新增缩进、额外段距或其它强调；
- 背景文字、战斗规则、AI 和性能均不受影响；
- 异常输入显示完整原文。
