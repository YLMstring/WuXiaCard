# 卡牌特效正文结构化排版设计

日期：2026-09-14

## 目标

在不减少信息、不改写卡牌文案、不改变能力或结算规则的前提下，降低卡牌详情中“特效”正文的阅读压力。

本次只调整完整规则的排版，不增加简明版、摘要、图标、展开按钮或新的玩家操作。“背景”正文保持现状。

## 玩家体验

卡牌详情仍显示目录中的完整 `description`，但不再把多个能力挤成一个连续文本块：

- 每个最外层完整句子形成一个独立段落；
- 段落之间留约半行的视觉间距；
- 不增加项目符号，不删改原句；
- 段首规则词使用略粗字重和现有棕色强调色；
- `【……】` 中的授予能力另起视觉行并缩进一级；
- “特效”标题、正文字号和正文主色保持现状；
- “背景”标题及正文完全保持现状。

详情页的轻触关闭、拖动滚动、初始滚动位置和模态输入行为均不改变。

## 强调词

只强调段落或嵌套句开头的规则词，避免在正文内部反复着色。首批识别以下形式及其合理组合：

- `锁定`
- `指定`
- `对局开始时`
- `回合开始时`
- `回合结束时`
- `进场前`
- `进场时`
- `进场后`
- `攻击时`
- `攻击后`
- `被攻击时`
- `翻面前`
- `翻面后`
- `被丢弃后`
- `被移除前`
- `被移除后`

例如 `锁定，指定：` 作为一个连续前缀整体强调。未被识别的词照常显示，不影响分段或文字完整性。

## 格式化规则

新增纯展示工具 `CardEffectTextFormatter`。它接收一个原始字符串，生成供 `RichTextLabel` 使用的安全富文本，不读取目录能力声明。

### 最外层分段

扫描字符串时维护中文方括号 `【】`、中文及英文圆括号 `（）()`、中文引号 `“”` 和英文引号的嵌套状态。

- 只在所有嵌套深度均为零时，将句号 `。` 视为段落边界；
- 句号仍属于原段落，不会被删除或移动；
- 原文已有的换行优先作为明确段落边界；
- 紧随上一句的括号备注仍附着于上一段，不单独形成段落；
- 逗号、分号和冒号不自动分段，避免拆开同一能力的条件与结果。

段落使用富文本段落标签和样式产生间距，不向原文插入可见项目符号。

### 授予能力缩进

遇到 `【……】` 时保留原有括号和全部原文，在外层说明之后建立一级缩进。方括号内部的最外层句号产生紧凑换行，但不使用外层段落的额外大间距。

嵌套内容中的规则词可以按同一段首规则强调。多层 `【】` 按实际深度继续缩进，但不重新解释或改写内容。

### 文本完整性

格式化只添加富文本控制标签。移除这些标签后，必须能够恢复原始文本；手工换行允许经过统一的换行符标准化。

原始文本中的 `[`、`]` 等富文本控制字符必须先转义，不能被解释为目录之外的样式指令。

### 异常回退

以下情况不尝试结构化分段，直接显示转义后的完整原文：

- 任意受支持括号或引号未闭合；
- 出现先闭合后打开的非法嵌套；
- 格式化后的纯文本无法还原原文；
- 富文本生成过程发现不支持的结构。

回退只损失本次排版增强，绝不隐藏文字，也不影响卡牌详情的其它字段。

## UI 架构

`card_inspector.tscn` 中的特效正文由普通 `Label` 改为 `RichTextLabel`：

- 开启富文本；
- 开启中文智能换行；
- 根据内容自动适应高度；
- 禁用它自己的滚动条，由既有外层 `ScrollContainer` 统一滚动；
- 保持忽略鼠标输入，使详情页现有的轻触和拖动手势继续由 `CardInspector` 处理；
- 字号继续由 `CardInspector.set_board_rect()` 按棋盘短边计算；
- 主体颜色保持现有深色，强调词使用现有标题棕色。

`CardInspector.present()` 仍保存并返回原始卡牌快照。只有写入特效正文控件时调用格式化器；`get_card_snapshot()` 中的 `description` 永远保持目录原文。

## 数据与规则边界

本功能不修改：

- `scripts/card_catalog.gd` 中任何描述或能力声明；
- 卡牌目录校验；
- `DuelState`、状态键或存档格式；
- 原生 C++ 规则与 AI 搜索；
- 对局事件、动画或输入合法性；
- 背景故事正文。

格式化器是纯 UI 工具，不进入搜索或结算热路径。

## 测试

### 格式化器单元测试

覆盖：

- 单段普通能力；
- 多个最外层能力；
- `锁定，指定：` 等复合前缀；
- `获得以下效果：【……】` 的一级缩进；
- 多句嵌套能力；
- 圆括号备注；
- 中文与英文引号；
- 手工换行；
- 富文本控制字符转义；
- 未闭合和非法嵌套的完整原文回退。

### 全目录守恒测试

遍历全部卡牌定义：

- 每条非空 `description` 均能成功格式化或安全回退；
- 移除格式标签后的正文与目录原文完全一致；
- 不产生未闭合的富文本标签；
- 空描述继续沿用详情页现有占位符。

### 详情页集成测试

确认：

- 特效正文使用结构化富文本；
- 背景正文仍是原有普通文本和样式；
- 卡牌快照保留原始描述；
- 初始滚动位置、拖动滚动和轻触关闭不变；
- 长文本能在 `540×960` 参考画布内正常滚动；
- 窄屏中文不出现裁字或横向溢出。

### 完成验证

运行完整测试套件，并在音乐和音效静音的情况下打开普通、多能力和嵌套授予能力三类卡牌，检查段距、强调、缩进和滚动手感。

## 验收标准

- 玩家看到的能力文字与当前目录逐字一致；
- 多能力卡可以按段快速扫读；
- 嵌套授予能力与外层效果具有清楚的视觉层级；
- 没有新增学习成本或操作步骤；
- 背景文字、战斗规则、AI 和性能均不受影响；
- 异常输入宁可显示普通完整文本，也不能漏字。
