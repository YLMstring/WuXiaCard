# 八卦方位与后手开局布局设计

日期：2026-08-20

## 目标

实装卡牌 `BaGuaFangWei` 的完整能力，并新增统一的对局开局规则：确定先手后，后行动的一方在九宫格中随机占据两个正交相邻的位置，各放置一张八卦方位。

八卦方位属于初始场面，不视为进场。它们在对局画面出现时已经静态位于棋盘上，不触发 `TRIGGER_CARD_BEFORE_SUMMONED`、`TRIGGER_CARD_SUMMONED`、`TRIGGER_CARD_AFTER_SUMMONED`、标准进场攻击或任何相关表现事件。

## 卡牌声明

`BaGuaFangWei` 保留现有目录数据：

- `picture`: `res://pics/bagua.png`
- `sect`: `江湖`
- `tier`: `6`
- `weapon`: `术数`
- `powers`: `[-1, -1, -1, -1]`
- `description`: `锁定：翻面前，将我移除。`

新增一个独立能力条目：

```gdscript
{
	"retained_on_flip": true,
	"triggers": [{
		"event": CARD_BEFORE_FLIPPED,
		"conditions": [{"type": CONDITION_TRIGGER_CARD_IS_SELF}],
		"actions": [{
			"type": ACTION_EXILE_CARD,
			"card": CARD_REF_TRIGGER_CARD,
		}],
	}],
}
```

该能力复用现有通用翻面前事件和通用移除动作。八卦方位在翻面实际发生前进入其原始拥有者的移除区，因此本次翻面不再继续。

`-1` 点数继续使用现有统一规则：卡面不显示点数，可以被任何点数的牌攻击，且不能成为加减点数效果的自动合法目标。

## 初始布局规则

九宫格按 `0..8` 行优先排列。候选位置是全部 12 组正交相邻的无序格位对：

```text
(0,1) (1,2) (3,4) (4,5) (6,7) (7,8)
(0,3) (1,4) (2,5) (3,6) (4,7) (5,8)
```

从这 12 组中直接等概率抽取一组，每组概率均为 `1/12`。不得采用“先等概率选一个格，再等概率选其邻格”的方式，因为该算法不会令 12 组最终布局等概率。

选定格位对后，按较小格位、较大格位的顺序创建两个全新实例：

- `card_id` 均为 `BaGuaFangWei`；
- `instance_id` 唯一且稳定；
- 当前所有者和 `original_owner` 均为后行动的一方；
- 直接写入初始棋盘，不产生事件；
- 不改变行动方、行动数、回合序号、手牌、牌库或移除区。

两张八卦方位此后是普通场上牌：占据格位、计入场上数量和终局计分、参与完全重复场面签名，并可成为攻击目标。

## 架构

新增纯数据模块 `scripts/duel_opening_setup.gd`，职责仅包括：

1. 构造稳定有序的 12 组相邻格位对；
2. 使用传入的 `RandomNumberGenerator` 等概率选择一组；
3. 为后手方创建两个目录实例并返回完整初始棋盘。

`DuelController` 仍负责组装对局，但不自行实现相邻判断或放置规则。它先确定 `opening_owner`，再将另一方传给开局设置模块，最后用返回的棋盘构造 `DuelState`。`DuelState` 继续只保存纯数据，`DuelSimulator`、搜索和表现层都消费同一初始状态。

控制器新增开局布局随机种子：

- `0`：生产环境随机；
- 正数：固定并复现布局；
- `-1`：仅供需要空棋盘的专项测试夹具关闭八卦方位。

正常模式和 testing mode 均默认启用八卦方位。

回放在开局布局完成后记录初始状态，因此重播复用原来的两个实例和格位，不重新随机，也不播放开局生成动画。

## 图片呈现

`bagua.png` 是 600×600 的正方形图片，其他常用牌图通常是 1000×1000。卡面现有 `TextureRect` 已使用忽略源像素尺寸、保持比例居中缩放，因此八卦图仍占据与其他正方形牌图相同的显示区域，不需要卡牌 ID 特判或专用缩放代码。

不增加八卦方位专门的长期渲染回归测试。完成实现后在生产场景中直接检查实际卡面，确认图片加载、居中、比例和可见性正常。

## 测试与验证

新增开局设置单元测试，覆盖：

- 候选集合恰好包含上述 12 组，无重复，且每组正交相邻；
- 相同固定种子得到相同布局；
- 两个选中格位之外均为空；
- 玩家先手时两张牌属于敌方，敌方先手时两张牌属于玩家；
- 两个实例 ID 不同，`card_id`、当前所有者和 `original_owner` 正确；
- 行动方、行动数、手牌和牌库不因初始布局改变。

目录/模拟器测试覆盖八卦方位的保留能力声明，以及受到攻击时在 `CARD_BEFORE_FLIPPED` 中被真正移除、不会完成翻面。

生产整合测试覆盖：

- 进入对局画面时两张牌已经静态显示；
- 两张牌位置相邻，棋盘恰有七个空位；
- 后手所有权与所选先手一致；
- 初始状态快照、搜索输入和回放初始状态包含同一布局。

修改前后运行仓库完整测试套件。实现完成后启动生产主场景，实际查看八卦方位图片与初始棋盘。

## 非目标

- 不新增对局开始触发事件。
- 不把八卦方位当作手牌、牌库或奖励卡生成。
- 不播放开局召唤动画。
- 不为 `bagua.png` 添加专用卡面布局代码或专门的渲染回归测试。
