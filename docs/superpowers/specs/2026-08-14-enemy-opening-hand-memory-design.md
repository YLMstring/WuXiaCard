# 敌方开局手牌记忆与岱宗如何设计

日期：2026-08-14

## 当前问题

岱宗如何使用 `ACTION_REVEAL_HAND_CARDS`、`RECIPIENT_OPPONENT` 和
`REVEAL_FILTER_REMEMBERED`。目标会随能力来源所有者正确反转，因此敌方使用时目标是玩家手牌；但当前只有玩家拥有敌方牌名记忆，敌方的记忆列表为空，所以敌方岱宗如何通常不会揭示任何玩家手牌。

## 对局初始化

- 创建 `DuelState` 时，继续把流程存档中的敌方牌名记忆写入玩家观察者的记忆列表。
- 同时从玩家本场开局的五张主卡组实例读取 `glyph`，去重后写入敌方观察者的记忆列表。
- 敌方记忆只存在于本场 `DuelState`，不写入 deck profile，也不跨对局保留。
- 测试模式、正常模式、贪心 AI、深度 AI 和回放均使用同一个初始化状态。

## 岱宗如何的行为

- 玩家使用岱宗如何时，行为不变：只揭示玩家此前记住的敌方牌名。
- 敌方使用岱宗如何时，揭示玩家当前手牌中 `glyph` 属于开局五张主卡组记忆的牌。
- 已离开手牌的开局牌不会被揭示；它之后回到手牌时仍匹配该记忆。
- 后续抽到同一 `glyph` 的其他阶级或其他 ID 也会匹配并被揭示，因为现有记忆系统按牌名而非运行时实例记录。
- 后续抽到不属于开局主卡组牌名的牌不会被揭示。
- 岱宗如何现有的“已揭示敌方牌进场时获得防御点数视为零”规则继续使用实际揭示状态，无需新增具名卡牌分支。

## 数据与架构

- 不新增揭示过滤器、卡牌动作或存档字段。
- 只补全 `remembered_glyphs_by_owner` 的敌方观察者条目。
- 记忆列表继续进入 `DuelState` 复制、状态键和回放开局快照，因此搜索与实际对局保持一致。
- 正常模式仍遮盖玩家看不到的敌方手牌；敌方对玩家的内部记忆不会造成额外 UI 信息泄漏。

## 验证

- 对局初始化后，玩家观察者保留原有敌方记忆，敌方观察者记住玩家五张开局主卡组的全部唯一牌名。
- 敌方岱宗如何揭示玩家手中所有匹配开局牌名的牌。
- 后抽的不同牌名保持未揭示。
- 后抽的同牌名不同 ID 会被揭示。
- 玩家岱宗如何的既有 remembered 过滤行为不变。
- 回放开局状态保留两方记忆。
- 运行完整测试套件：`powershell -ExecutionPolicy Bypass -File tools/run_tests.ps1`。
