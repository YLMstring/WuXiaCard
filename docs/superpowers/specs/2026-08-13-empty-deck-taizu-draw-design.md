# 空牌库抽太祖长拳设计

日期：2026-08-13

## 规则

- 本规则统一作用于 `ACTION_DRAW_CARDS`，不由具体卡牌单独声明。
- 抽牌逐张结算。每个抽牌名额先尝试抽取所属方牌库顶牌。
- 若结算某个名额时牌库为空，则创建一张新的 `TaiZuChangQuan`，直接加入该方手牌。
- 一次抽多张时，每个缺失名额分别创建一张。因此空牌库执行“抽两张”会获得两张新的太祖长拳；牌库剩一张而执行“抽三张”时，会先抽原牌，再创建两张太祖长拳。
- 新牌不经过牌库，牌库保持为空。
- 抽牌仍受五张手牌上限约束。超出手牌容量的名额既不抽牌，也不创建太祖长拳。

## 运行时身份与事件

- 每张生成的太祖长拳都通过卡牌目录创建独立运行时实例，并取得不重复的 `instance_id`。
- 生成牌沿用抽牌方作为当前及原始所有者。
- 正常发出 `card_drawn`，并沿用未来抽牌揭示等现有后续流程；表现层无需识别特殊事件。

## 实现边界

- 修改通用抽牌执行器，不在 `DuelController` 或具名卡牌分支中实现。
- 不改变牌库构建、洗牌、弃牌、移除或回收规则。
- 搜索与实际对局继续共用模拟器路径。

## 验证

- 空牌库抽两张会得到两张不同实例的太祖长拳，并产生两个 `card_drawn` 事件。
- 牌库只剩一张而抽多张时，先保持牌库顶顺序，再用太祖长拳补足名额。
- 接近五张手牌时只补到上限。
- 原有抽牌顺序、事件顺序、未来抽牌揭示和状态复制测试继续通过。
- 运行完整测试套件：`powershell -ExecutionPolicy Bypass -File tools/run_tests.ps1`。
