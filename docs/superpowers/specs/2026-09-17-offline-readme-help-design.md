# 离线 README 帮助页设计

## 目标

玩家可以从主菜单打开完整的 `README.md`，在 Windows 和 Android 上均可离线阅读，不调用系统浏览器，也不依赖网络。

## 主菜单入口

- 在主菜单现有提示文本的区域放置一个无文字的书本图标按钮。
- 图标采用与现有水墨 UI 一致的单色笔触风格，并提供与其它可点击图标一致的按压缩放、回弹和手机轻震反馈。
- 书本按钮与提示文本互斥：提示文本为空时显示按钮；需要显示任何提示文本时隐藏按钮。
- 结束滚动场景复用主菜单时，现有提示文本节点会被整体隐藏，作为其子节点的书本按钮也随之隐藏，不出现在结局画面中。

## 阅读页

- 点击书本按钮后，在当前主流程中切换到独立的全屏“江湖指南”场景。
- 阅读页沿用主菜单音乐上下文，不触发换曲。
- 页面使用竖屏安全区、可滚动富文本和右上角返回箭头；返回后重新创建普通主菜单。
- 正文直接来自随安装包打包的根目录 `README.md`，不维护第二份人工同步的帮助文本。
- 支持 README 当前使用的标题、段落、粗体、无序列表、有序列表、代码块、分隔线和目录内部跳转。
- Markdown 中的 HTML 锚点只用于内部定位，不显示为正文。
- 外部链接保留可读文字，但不从游戏内发起联网或打开外部浏览器。
- 无法识别的 Markdown 语法退化为可读纯文本，不能导致整页加载失败。

## 打包与失败处理

- Windows 与 Android 导出预设显式包含 `README.md`，确保 `FileAccess` 可以从 `res://README.md` 读取。
- 若资源缺失或读取失败，阅读页显示“说明文件加载失败”，返回按钮仍然可用。
- Markdown 转换只属于展示层，不修改 README，不写入存档，也不影响游戏规则或进度。

## 测试与验收

- 主菜单无提示时显示书本按钮；显示提示时按钮隐藏；清除提示后按钮恢复。
- 结局场景不显示书本按钮。
- 点击入口可进入阅读页，返回可回到主菜单，音乐上下文保持为主菜单。
- 目录项能跳到对应章节，长文滚动到底部后技术细节仍可阅读。
- 在 540×960、20:9 长屏和 16:9 短屏下检查安全区与换行。
- 使用导出的 Windows/Android 包确认 README 确实随包存在并可在断网状态读取。
- 运行主菜单、主流程、结局场景和新增帮助页的定向测试；本次 UI 改动不运行完整套件。
