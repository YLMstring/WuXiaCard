# 中文 README 设计

日期：2026-08-26

## 目标与读者

将仓库根目录 `README.md` 重写为中文单页说明书。主要读者依次为：第一次接触游戏的玩家、需要查阅精确通用规则的熟练玩家、准备运行或维护项目的开发者。

README 必须由浅入深。前半不要求读者理解卡牌游戏术语；技术名词和实现边界统一放在最后。正文不逐张罗列卡牌能力，只解释通用规则，并用少量卡牌或场景作例子。

## 结构

1. 简单介绍：用短段落说明武侠题材、九宫格、四边点数、单人闯关和组牌成长。
2. 跳转目录：使用显式英文 HTML 锚点，确保中文标题在 GitHub 和其它 Markdown 阅读器中稳定跳转。
3. 三分钟看懂怎么玩：用日常语言解释目标、卡牌四边、出牌、攻击、翻面、回合和胜负。
4. 新手第一次游玩指引：按实际界面顺序介绍主菜单、选门派、组五张主牌、先后手、内力、奖励、解锁、重开与实用建议。
5. 具体结算规则：分点说明棋盘、点数方向、攻击合法性、进场与标准攻击、指定攻击、翻面与所有权、能力保留、移动、手牌、抽弃移除、触发时点、额外出牌、回合边界、终局、隐藏信息、敌人记忆和回放。
6. 技术细节：说明 Godot/Summer Engine 版本、权威模拟器架构、核心目录、运行方式、测试命令、Android 配置、贡献约束和进一步文档入口。

## 写作原则

- 规则入门部分使用短句、具体例子和玩家能看到的界面用语。
- 首次出现“翻面”“内力”“移除”等术语时立即解释。
- 精确规则部分明确区分普通出牌、主动能力、标准攻击和效果发起的指定攻击。
- 不把历史计划当成现状；事实以当前生产代码、通过的测试、`docs/HANDOFF.md`、`docs/ARCHITECTURE.md` 和 `docs/DECISIONS.md` 为准。
- 对尚未完成或仅供开发使用的功能作明确标注，不写成已发布能力。
- 保留可复制的 PowerShell 测试命令和仓库文档链接。

## 验证

- 检查目录中的每个链接都能落到对应锚点。
- 对照当前代码与规则文档复核点数方向、手牌槽位、先后手、内力、攻击、终局、奖励、解锁、重开、回放和测试命令。
- 搜索并删除旧 README 中“尚无组牌/成长”等已经过期的描述。
- 运行 Markdown 基础检查：无尾随空格、无坏的本地相对链接、代码块成对闭合。

## 非目标

- 不制作逐卡百科、完整敌人图鉴或剧情攻略。
- 不修改游戏代码、资源、规则或界面。
- 不承诺尚未完成的发布、联网或多玩家功能。
