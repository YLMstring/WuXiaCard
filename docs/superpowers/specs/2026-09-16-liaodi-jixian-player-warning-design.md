# 料敌机先玩家出牌警告设计

## 目标

当正常模式中的玩家处于可出牌决策阶段，且玩家当前仍有至少一层
`pending_non_retained_suppression_by_owner[PLAYER_OWNER]` 时，将战斗界面下方的默认提示
“你的回合 · 拖动卡牌”替换为“本次打出的手牌将永久失去效果”。

## 状态与显示

- 直接读取 `DuelState` 已有的待失效层数，不新增规则状态、事件或卡牌 ID 判断。
- 只替换正常模式玩家回合的默认提示；测试模式保留现有测试提示。
- 卡牌检视、对手回放、结算中、对手思考和终局提示继续保持现有更高优先级。
- 待失效层被下一次手牌出牌消耗后，下一次刷新恢复默认玩家回合提示。

## 验证

- 集成测试构造玩家待失效层大于零的决策局面，确认显示警告。
- 清除待失效层并刷新，确认恢复默认提示。
- 运行完整自动化测试套件，确认其它提示和规则不受影响。
