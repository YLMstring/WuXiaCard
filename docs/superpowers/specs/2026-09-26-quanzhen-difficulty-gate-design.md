# 全真派按进阶进入随机内容的设计

## 目标与边界

全真派从进阶 4 起进入每局五门派随机池；进阶 0–3 的随机池不含全真派。进阶 0–3 的正式流程不会随机抽到牌组中含有任何全真派卡的敌人，进阶 4–10 可正常抽到。判断依据是敌人实际牌组中卡牌目录的 `sect == "全真派"`，而非敌人姓名或可解锁门派的 `sect_id`。本次只限制随机内容；调试、测试用显式敌人 ID 仍允许指定全真敌人。若玩家已经解锁全真派，开局门派选择在所有进阶均可选择它，所选门派的初始牌和后续所属门派奖励正常获取。

本设计不改卡牌规则、能力声明、卡牌目录中的任何 `abilities` 数组，也不因随机门槛隐藏或撤销已经解锁的牌。

## 现状

`SectCatalog` 已有 `QuanZhenPai` 定义，`EnemyCatalog` 已有全真弟子、孙不二、丘处机三行；它们还没有进入各自的 `ALL_SECT_IDS` / `ALL_ENEMY_IDS`。当前目录校验因此失败，依赖门派选择初始化的测试连带失败。注册这些现有定义是本次实现的前置修复。

`DeckProfileStore.begin_run()` 选择玩家门派和进阶，然后调用 `_pick_run_sect_pool_ids()` 固定本局五门派；读取旧存档时 `_repair_run_sect_pool_ids()` 可重建缺失或损坏的池。正式敌人在开局及每场胜利后的 `_choose_enemy_id()` 中产生，并通过 `EnemyCatalog.pick_random_enemy_id()` 按等级随机。显式敌人 ID 也经 `_choose_enemy_id()`，因此必须保留其绕过随机过滤的路径。

## 方案

`SectCatalog` 的每个门派定义都必须显式声明 `min_random_difficulty`，数值在进阶 `0..10` 内。它控制该门派何时进入随机门派池，以及携带其门派牌的敌人何时进入随机敌人候选；以后调整任一门派，只需修改该门派目录数值，不改抽取代码。当前配置如下：

| 门派 ID | `min_random_difficulty` |
| --- | ---: |
| `HuaShanPai` | 0 |
| `ShaoLinPai` | 0 |
| `WuDangPai` | 0 |
| `TaiShanPai` | 0 |
| `HengShanPai` | 0 |
| `tingchao_gu` | 0 |
| `SongShanPai` | 0 |
| `QuanZhenPai` | 4 |

`SectCatalog` 提供纯数据查询，回答门派 ID 或卡牌的门派文字在指定进阶是否可进入随机内容，并对每条定义校验该字段的类型与范围。`get_all_sect_ids()` 继续返回全部门派，以便解锁、展示与手动选择不受随机门槛影响。

`DeckProfileStore._pick_run_sect_pool_ids()` 使用当前 `difficulty` 排除不开放的候选；`_repair_run_sect_pool_ids()` 用存档中的 `run_difficulty` 过滤旧池并按既有稳定种子补足五门派。已有的所选门派排除规则保持不变：玩家在进阶 0–3 手动选择全真派时，随机池只从其他开放门派取五个。存档校验要求固定随机池中的门派符合本局进阶，但不限制 `selected_sect_id`，也不清理玩家已经拥有的全真牌。

`EnemyCatalog` 保留按等级列出全部已配置敌人的目录 API；新增按进阶筛选随机候选的入口。它逐一读取候选敌人的五张牌，以卡牌目录的门派文字查上述开放条件。`DeckProfileStore` 只在未传显式敌人 ID 的分支使用该随机入口，并传入本局 `run_difficulty`；已有显式 ID 分支仍只校验敌人存在及等级匹配。这样全真派敌人的 `sect_id` 是否存在不会改变判定，混合牌组中只要有一张全真派牌也受限。

不选采用在 `DeckProfileStore` 和 `EnemyCatalog` 各写一份 `QuanZhenPai` 特判的方案，因为它会让随机池与敌人规则分叉。也不在每个全真敌人上重复声明进阶门槛，因为牌组一旦修改，声明可能与实际内容不一致。

## 验证

先固定当前失败基线并补聚焦测试：目录完整注册；进阶 3 的新局和修复后的旧池都不含全真派，进阶 4 可包含；已解锁玩家在进阶 0 手选全真派可开局；等级 4、6、10 的全真敌人在进阶 3 的随机候选中消失、进阶 4 重新出现；仅混入一张全真牌的敌人也被过滤；显式指定敌人 ID 仍可进入测试局。确认每个等级仍至少有一个可选随机敌人，固定 RNG 仍可复现。随后运行完整套件，并在 540×960 竖屏走开局选门派与进入对局的生产路径。
