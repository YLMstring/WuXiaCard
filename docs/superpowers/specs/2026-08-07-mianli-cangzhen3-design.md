# 绵里藏针3能力设计

日期：2026-08-07

## 目标

实现目录中绵里藏针3的两段能力：

1. 我将敌方翻面后，若其最初是友方，使其重新进场。
2. 敌方攻击后，若本次攻击中有在我攻击范围内的友方被翻面，我发起攻击，然后失去此效果。

第二段直接复用现有 `HENGSHAN_COUNTERATTACK`。本设计重点是第一段通用的原格重新进场规则及其表现。

## 目录声明

绵里藏针3加入 `ALL_CARD_IDS`，但不加入新档案默认锁定列表。因此新档案会按现有默认规则拥有这张卡。其 `abilities` 为：

```gdscript
"abilities": [MIANLI_RESUMMON, HENGSHAN_COUNTERATTACK]
```

`MIANLI_RESUMMON` 声明为：

```gdscript
const MIANLI_RESUMMON: Dictionary = {
	"triggers": [{
		"event": CARD_AFTER_FLIPPED,
		"conditions": [
			{"type": CONDITION_ATTACKER_CARD_IS_SELF},
			{"type": CONDITION_TRIGGER_CARD_ORIGINAL_OWNER_IS_SELF},
		],
		"actions": [{"type": ACTION_RESUMMON_TRIGGER_CARD_IN_PLACE}],
	}],
}
```

两段能力都不声明 `retained_on_flip`，因此绵里藏针3易主后会失去它们。

## 新通用原语

### 条件

`CONDITION_TRIGGER_CARD_ORIGINAL_OWNER_IS_SELF` 比较：

- 触发牌的 `original_owner`；
- 能力来源牌在条件结算时的当前所有者。

两者相同才通过。该条件只依赖纯模拟数据，供玩家、测试模式、贪心 AI 与深度搜索共用。

### 动作

`ACTION_RESUMMON_TRIGGER_CARD_IN_PLACE` 使用触发上下文中的精确 `trigger_instance_id`：

1. 在动作即将结算时重新定位该实例。
2. 若实例已不在场，返回 `NO_EFFECT`。
3. 单纯移动不取消动作；使用实例此刻所在的格子作为重新进场格。
4. 从棋盘移除旧实例，但不计为放逐，也不加入移除区。
5. 以相同 `card_id` 从目录创建全新实例。
6. 新实例的当前所有者与 `original_owner` 都设为能力来源牌在动作结算时的当前所有者。
7. 在步骤 3 记录的原格放置新实例。

新实例获得新的 `instance_id`，并完全重置为目录状态，包括气、四向战力、能力及所有临时修正。它不继承旧实例的运行时状态。

## 重新进场结算顺序

重新进场不是从手牌打出，不记录手牌出牌或精通候选。成功放置新实例后按正常召唤顺序结算：

1. 发出旧实例为重新进场而离场的纯数据事件。
2. 放置新实例并发出 `card_summoned`。
3. 结算全局 `TRIGGER_CARD_SUMMONED`。
4. 若精确新实例仍在场，结算它当前拥有的 `TRIGGER_CARD_AFTER_SUMMONED`。
5. 若它仍属于重新进场的所有者，执行一次标准攻击。
6. 返回原 `CARD_AFTER_FLIPPED` 触发队列，继续后续规则。

任何进场反应都能正常移动、翻面或移除新实例。标准攻击只在上述重新检查通过时发生。

## 表现

规则层发出一个新的纯数据离场事件，明确区分重新进场、放逐与返回手牌。

控制器按事件顺序呈现：

1. 原格旧 CardView 渐隐并删除。
2. 渐隐完成后，后续 `card_summoned` 使用既有墨召效果创建新 CardView。
3. 墨召完成后，继续呈现进场触发与标准攻击。

旧实例不播放放逐动画。渐隐与墨召不重叠，以保证手机屏幕上的身份替换清晰可读。

## 边界规则

- 目标在动作前已离场：动作无效果。
- 目标仅仅移动：在移动后的当前格重新进场。
- 能力来源在触发条件结算前已离场：现有触发上下文失效规则处理，不执行。
- 能力来源在动作结算前易主：新实例归动作结算时的来源当前所有者，且 `original_owner` 同样设为该所有者。
- 目标的旧实例不进入放逐区，因此不会触发未来只监听放逐的规则。
- 新实例可正常攻击，并可触发由该次攻击造成的所有后续效果。
- 重新进场过程中没有玩家选择，回放与 AI 可确定性重演。

## 测试

新增聚焦模拟器与集成测试，覆盖：

- 目录接受新条件、动作和绵里藏针3声明；
- 只有来源自己完成翻面且目标最初属于来源所有者时触发；
- 其他攻击者、非原友方目标不触发；
- 新旧实例 ID 不同，新实例恢复目录初始状态；
- 目标移动后在当前格重新进场；
- 目标已离场时返回 `NO_EFFECT`；
- 完整结算两阶段进场触发和标准攻击；
- 绵里藏针3同时保留并正常消耗 `HENGSHAN_COUNTERATTACK`；
- 控制器先记录旧视图渐隐，再记录新视图墨召；
- 新卡不在默认锁定列表，新档案按现有规则拥有它；
- AI 克隆、回放和生产控制器继续使用相同模拟事件。
