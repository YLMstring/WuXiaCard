# 寒冰真气与天外玉龙能力设计

日期：2026-08-11

## 目标

完整实装当前卡牌目录中 `HanBinZhenQi3`、`HanBinZhenQi4`、
`TianWaiYuLong2` 与 `TianWaiYuLong3` 的描述能力，同时保持
`DuelSimulator` 为人类操作、测试模式、贪心回退和深度搜索的唯一规则路径。

实现必须保持卡牌无关：目录只组合通用事件、条件、目标规则和动作；模拟器、
搜索与控制器不得检查上述卡牌 ID。

## 已确认的规则

### 寒冰真气的主动指定

- 两阶寒冰真气都以棋盘卡主动指定对手的一张手牌。
- 发动任何主动能力仍统一消耗一点内力。
- 目标在支付费用前按精确 `instance_id` 锁定。目标所有者也保存为不可变快照。
- 普通目标四边点数减一，然后对能力来源的发动时所有者永久揭示。
- 全四边为 `[-1, -1, -1, -1]` 的阴阳掌力仍是合法的主动指定目标。
  发动会支付内力并揭示该精确实例，但点数变化返回 `NO_EFFECT`。
- 空手牌槽、己方手牌槽、缺失实例和过期逻辑索引不是合法目标。
- 对手手牌在普通模式下即使保持背面，也可以作为合法拖放目标；选择过程不得泄露
  卡牌元数据。

### 寒冰真气四阶的最后内力

- 四阶监听自身内力从正数降到零的边界，而不是仅检查某种特定消费动作。
- 用最后一点内力发动指定时，顺序是：支付内力并产生内力变化事件；立即完成
  寒冰真气翻面及其翻面后规则；随后继续处理已锁定目标的减点与揭示。
- 翻面后，原先选定的手牌仍是本次目标。即使所有权变化使它相对于寒冰真气当前
  所有者变成友方，也不重新按敌我关系筛选。
- 内力没有发生从正数到零的变化、来源已经离场、来源已不是预期所有者或翻面已
  无意义时，翻面请求返回 `NO_EFFECT`。

### 寒冰真气翻面后获得的能力

- 寒冰真气第一次翻面后获得一个非保留能力：当前所有者回合开始时，使自身和
  当前手牌中最左侧的两个合法目标四边点数减一。
- 自动手牌选择先过滤全四边 `-1` 的阴阳掌力，再按当前逻辑手牌从左到右取两个；
  被过滤的牌不占数量限制。
- 少于两个合法目标时，对所有实际合法目标结算；没有合法目标时仍可对自身结算。
- 自身与手牌目标属于同一个点数变化表现批次：所有可见旧点数共同停顿，然后同时
  播放减点动画。隐藏手牌仍不增加等待时间或泄露信息。
- 普通减点继续逐边以零为下限；四边成为零时，精确实例进入其原所有者的移除区。
- 负责首次授予的翻面后触发器是一次性的。新获得的回合开始能力非保留；寒冰真气
  后续再次翻面时永久失去，不会再次获得。

### 天外玉龙

- 两阶都监听友方牌在相邻格进入场上的全局进场事件。
- 二阶顺序为：重新验证精确触发牌仍为相邻友方；天外玉龙与该牌交换位置；天外
  玉龙从交换后的新位置发起一次完整标准攻击。
- 三阶先尝试使精确触发牌四边点数加一，再执行同样的交换与攻击。
- 若三阶触发牌是全四边 `-1` 的阴阳掌力，加点返回 `NO_EFFECT`，但交换和攻击继续。
- 攻击者始终是天外玉龙。攻击时重新读取其当前位置、当前所有者与当前合法目标。
- 交换沿用现有移动边界：两张精确实例分别处理移动前事件、重新验证、移动和移动后
  事件。任何一腿失败都会使交换失败。
- 交换失败会停止本条规则的后续动作，天外玉龙不会从原位置攻击。
- 多个来源按现有行优先、能力顺序和触发顺序逐条完整结算。后续来源根据前一次交换
  后的棋盘重新验证相邻和友方关系。
- 天外玉龙的交换攻击结算完毕后，原进场友方才继续其进场后能力，并从交换后的当前
  位置执行自己的普通进场攻击（前提是仍由进场所有者控制）。

## 通用数据词汇

### 敌方手牌目标

新增一个目录目标规则，用于枚举能力来源发动时所有者的对手手牌。合法动作沿用
`DuelAction.TARGET_HAND_SLOT`；`target_index` 是发动时对手手牌数组的逻辑索引。

`DuelTargeting` 负责枚举及验证。AI、测试模式和人类输入均使用同一合法动作。
控制器通过被拖到的固定物理手牌槽中的精确卡牌视图，反查当前逻辑索引后提交动作。

### 精确单卡揭示

新增通用揭示动作，接受现有精确卡牌引用。动作按引用快照寻找当前精确实例，并对
声明的观察者揭示。已经对该观察者揭示时返回 `NO_EFFECT`，且不重复发事件。

寒冰真气使用 `CARD_REF_SELECTED_CARD` 与相对于发动时所有者的观察者。揭示不得依赖
能力来源在后续动作执行时仍保持原所有权。

### 内力变化事件

新增通用内力变化触发边界，至少携带：精确来源实例、来源当时位置与所有者、旧内力、
新内力以及变化原因。每个成功的内力变化动作在其 `ki_changed` 事件之后立即请求处理
该触发边界，并在执行下一条规则动作前完成所有触发组。

新增条件表达“旧内力大于零且新内力为零”。四阶寒冰真气以该条件及“变化卡牌是自己”
请求普通翻面。规则不判断具体消费动作，因此未来其他合法内力损失也可触发。

### 与触发牌交换

新增通用动作，使能力来源与当前触发上下文中的精确棋盘牌交换。动作复用既有交换和
移动前后事件，不建立第二套移动逻辑。天外玉龙为该动作声明
`on_invalid_context = STOP_RULE`，随后再声明标准攻击。

### 跨动作点数批次

现有执行器默认以顶层动作索引划分点数变化批次。为表达“自身加上自动选择目标”这种
分开的通用动作组合，允许相关顶层动作声明同一过渡期批次组。批次 ID 仍由能力来源、
触发事件、能力/触发索引和组名共同生成，不进入 `DuelState`、目录运行实例、搜索键或
回放记录。

## 模拟数据流

### 寒冰真气主动能力

1. 模拟器验证棋盘来源、当前所有者、内力费用和敌方手牌目标。
2. 执行器在费用前保存目标精确实例及发动时双方关系。
3. 支付一点内力并发出 `ki_changed`。
4. 若四阶跨过最后内力边界，立即处理普通翻面：翻面事件使原能力按普通规则失去，
   一次性翻面后规则授予新的非保留回合开始能力并移除自身。
5. 使用步骤 2 的快照尝试减点。阴阳掌力返回 `NO_EFFECT`。
6. 对步骤 2 的精确实例执行揭示。
7. 完成原发动者的行动边界；翻面不会改变本次行动归属。

### 天外玉龙友方进场

1. 发现并按现有顺序解析 `TRIGGER_CARD_SUMMONED` 组。
2. 三阶先对精确触发牌尝试加一。
3. 重新验证相邻友方关系，解析两条移动腿并交换。
4. 交换成功后，天外玉龙从当前格完整执行标准攻击。
5. 返回原进场流程，继续该精确触发牌的进场后阶段与普通攻击。

## 表现与输入

- 棋盘主动卡继续使用现有指向线。敌方手牌合法目标槽提供与棋盘目标一致强度的高亮，
  但背面不显示名称、点数、能力或图片。
- 松手命中含合法精确实例的槽才提交动作；空槽或过期槽播放现有无效拖放反馈。
- `card_revealed` 继续由控制器同步现有手牌视图，不创建新的卡牌视图或布局节点。
- 寒冰真气回合开始的多个可见减点目标共享现有前置停顿和并行动画时长。
- 天外玉龙交换继续使用现有双卡移动表现，随后才播放从新位置发出的攻击表现。
- 不新增专属音效、图片、VFX 节点或卡牌 ID 表现分支。

## 失败与边界语义

- 主动目标在动作提交前必须是发动时对手手牌中的精确实例；动作开始后的翻面不使该
  快照失效。
- 目标在支付费用后因其他规则离开所有区域时，减点和揭示都返回 `NO_EFFECT`；已支付
  的费用与已经发生的翻面不回滚。
- 阴阳掌力只对自动点数选择非法；主动选择本身合法。
- 回合开始手牌选择以触发开始时的稳定实例快照为准，每个实例在执行前重新检查仍在
  手牌、仍属于当前来源所有者且点数可变。
- 天外玉龙交换前，来源或触发牌离场、所有权变化、不再相邻或位置被占用均使交换失败
  并停止后续攻击。
- 三阶加点失败不等同于交换失败；只有交换动作声明停止规则。
- 所有缺失或陈旧上下文返回 `NO_EFFECT`，不抛出场景侧规则分支。

## 验证范围

### 目录和纯规则

- 四张卡牌声明完整且通过目录校验。
- 新目标、事件、条件、动作及字段接受合法数据并拒绝未知或错误类型。
- 敌方手牌目标枚举保持逻辑从左到右且不泄露内容。

### 寒冰真气

- 两阶普通指定：支付、减点、揭示和事件顺序。
- 空槽、己方槽、无内力、陈旧索引及缺失实例非法。
- 主动选择阴阳掌力：合法支付、无点数事件、成功揭示。
- 四阶最后内力严格顺序：`ki_changed`，完整翻面/能力失去与授予，然后目标
  `powers_changed`（若适用）与 `card_revealed`。
- 翻面后能力按最左两个合法手牌目标选择，跳过阴阳掌力并顺延。
- 自身与手牌目标共享表现批次；少目标、无目标、隐藏手牌和重复实例变化正确。
- 点数归零移除及再次翻面永久失去能力。

### 天外玉龙

- 上、右、下、左四个相邻方向交换，且攻击来源格为交换后位置。
- 三阶加点在交换和攻击之前；阴阳掌力加点无效但继续。
- 非相邻、敌方、已移动、已翻面或已移除触发牌不会交换或攻击。
- 交换过程中移动前规则造成的失效会取消后续攻击。
- 多个天外玉龙按稳定顺序重验；友方进场牌随后从新位置完成自己的后续阶段。

### 集成与完成标准

- 搜索枚举并模拟敌方手牌主动目标，不检查卡牌 ID。
- 正常模式可瞄准背面手牌而不泄露信息；测试模式双方操作对称。
- 控制器按精确实例同步揭示、点数、翻面、交换和攻击。
- 完整自动测试套件通过。
- 在 540×960 逻辑视口实际走完两阶寒冰真气和两阶天外玉龙的受影响流程，运行时无
  新错误或警告。
